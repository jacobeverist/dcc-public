Embed example — human-readable JSON config

The config below is defined as plain, indented JSON inside a <script type="application/json"> tag. The page's bootstrap script reads it, encodes it once into the iframe URL hash, and mounts embed.html. Edit the JSON block and reload — no hand-encoding needed. See playground.html for an interactive flag-toggle builder, or README for the full config schema.

The config (live, read from the <script> tag)


        

        

            
How the script wires it up

            
const raw = document.getElementById('embed-config').textContent;
const cfg = JSON.parse(raw);
iframe.src = 'embed.html#' + encodeURIComponent(JSON.stringify(cfg));
